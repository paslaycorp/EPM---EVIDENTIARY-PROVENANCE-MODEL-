## C-21 classification

C-21 is **PASS — BOUNDED FAP RECEIPT** for the production claim actually implemented.

The production connector attests that, after authentication, FAP observed an exact SHA-256 evidence reference at its timezone-aware server receipt time. It does not backdate availability to the claimed capture/event time and does not claim that the underlying media existed externally before receipt.

Retroactive target epistemic states preceding trusted receipt are blocked. Missing/untrusted availability fails closed when required.

A stronger media-origin/pre-receipt existence claim remains outside this connector and requires an independent provenance source capable of making that stronger claim.

## Observability boundary

FAP now records structured EPM transition telemetry for decision, failure, assurance state, availability state, latency, fail-closed status, and source degradation. The current registry is process-local and non-durable; restart resets counters. This is operational observability, not a truth/confidence scoring system.

## Preserved exclusions

The following remain outside EPM v0.1.0:

- Temporal Verification Closure (TVC);
- Variant Hunter;
- universal truth scoring;
- universal domain completeness;
- universal media-origin or pre-receipt provenance claims.

## Freeze rule

After this finalization branch passes EPM Runtime CI again with the release evidence documents present, merge it to main, freeze the resulting EPM release commit, repin FAP-Insurance to that exact EPM commit, rerun the full FAP production gate, and promote only the repinned tested FAP commit.
